# Nivaar — Quiet clarity redesign

The Nivaar redesign brief governs implementation; the separate Sellix single-file demo is a visual reference, not a replacement architecture. Next.js/FastAPI and API contracts remain intact.

Original SVG light threads provide a static navy/cobalt opening background. No third-party video, stock identity, external font request or animation library is needed. Headline line-rise, subtitle focus/lift and pill entrance use finite CSS animations; a timed completion state prevents replay when returning to the check view. Reduced-motion CSS disables all animation and transitions. Content is visible by default and never depends on animation-end callbacks or network fonts.

`components/cinematic-hero.tsx` and `components/product-navigation.tsx` separate the new UI from workflow logic. `app/cinematic.css` defines the theme and responsive rules; existing structural styles use semantic dark tokens. Header navigation, language/provider controls, input tabs and consent, investigation states, reports, source/history views, emergency dialogs and footer share the theme. The main workflow scrolls naturally below the hero. Desktop uses readable fluid type, not proportional viewport scaling. Docker now copies the new components directory.

Design guidance: installed UI UX Pro Max (accessibility, minimal hierarchy, trust-blue palette); 21st.dev Spotlight reference at https://21st.dev/@manuarora700/components/spotlight (composition inspiration only, no copied component source). No fabricated statistics, testimonials or certifications.
