# Nivaar — Civic Clarity

The selected interface uses horizontal navigation, one primary intake, and a sequential assessment: verdict, reasons, official evidence, then next actions. A narrow desktop help rail explains the check and provides emergency guidance.

Navy and cobalt-blue branding, high-contrast text, comfortable reading sizes, self-hosted multilingual typography and restrained status colours replace the earlier decorative sidebar and empty-result illustration. Input tabs support arrow/Home/End keyboard navigation. Dialogs are labelled; result headings receive focus after investigation.

References: Origin UI stepper and Sean Hello file upload on 21st.dev, plus GOV.UK service patterns. Existing project primitives are adapted; no hosted AI generation or copied component code is used. The CLI catalog requires authentication, so public previews ground the composition.

Canonical decisions and constraints are recorded in design.json.
